## ブラインド食体験ランダマイザー

試料をランダム番号で隠してブラインドテストを公平に実施し、正解発表・スコア集計まで一気通貫でサポートするパーティツール。

### 機能
- 試料名・参加者名の入力（コーラ・ビール・コーヒー等テンプレートプリセット付き）
- 試料へのランダム番号割り当て（試料名を秘密にして番号のみ表示）
- 参加者ごとの「番号→試料名」予測入力
- ドラマチックなアニメーション付き正解発表
- 参加者別正解数スコア集計・ランキング表示
- localStorage による過去テスト結果保存（最大10件）

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- localStorage 永続化
- htmlEscape() によるXSS防止
